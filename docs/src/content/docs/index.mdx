## Features

<CardGrid stagger>
  <Card title="Type-Safe Configuration" icon="seti:typescript">
    Define your Workers configuration in TypeScript with full type inference for
    all bindings. No more guessing what options are available.
  </Card>
  <Card title="Auto-Generated wrangler.jsonc" icon="setting">
    Write your config once in `bw.config.ts` and let better-wrangler generate
    the correct `wrangler.jsonc` files automatically.
  </Card>
  <Card title="Monorepo Support" icon="stack">
    Run multiple Workers in parallel with the Miniflare-based dev server.

  </Card>
  <Card title="Automatic Migrations" icon="rocket">
    Durable Object migrations are tracked and managed automatically. No manual
    migration configuration needed.
  </Card>

## Quick Example

```typescript
// bw.config.ts
import { Worker, D1, KV, DurableObject, type InferEnv } from "better-wrangler";

const db = D1({ name: "my-database" });
const cache = KV({ name: "my-cache" });
const counter = DurableObject({
  name: "counter",
  className: "Counter",
  classPath: "./src/counter.ts",
});

export const api = Worker({
  name: "api",
  entryPoint: "./src/index.ts",
  bindings: { db, cache, counter },
});

export type Env = InferEnv<typeof api>;
```

Then run:

```bash
bw dev    # Start all workers in development mode
bw sync   # Generate wrangler.jsonc files
```
